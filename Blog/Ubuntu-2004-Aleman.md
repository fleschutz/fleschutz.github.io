El nuevo Ubuntu 20.04 LTS
====================

**Exactamente hoy, 23 de abril de 2020, se ha lanzado la nueva versión del sistema operativo Ubuntu 20.04 LTS con el bestial nombre en clave "Focal Fossa" (ver imagen). Ofrece una gran cantidad de funciones (también nuevas) de las que muchos otros sistemas operativos podrían sacar mucho provecho (¡sí, especialmente Windows!)**. 

... ![Image](/img/MF.png) *Por Markus Fleschutz* 🕓 *23 de abril de 2020*

Estas son las características que ofrece la nueva versión: 

* **Es gratis** y nadie tiene que perder funciones o seguridad sólo por no haber pagado. Aunque se aceptan con gusto las donaciones y hay clientes de pago, sólo recibirán un apoyo más prolongado.
* **Los lanzamientos planificables** se publican cada año en abril y octubre. Y cada dos años llega una versión LTS con soporte de actualización extra largo, como la versión 20.04 de hoy.
* **Actualizaciones durante 5 años:** el LTS significa Long Term Support, esto significa 5 años de suministro con actualizaciones de seguridad así como actualizaciones normales (de lo contrario son 3 años). Para los clientes de pago, este periodo se amplía incluso a 10 años. Por supuesto, es posible cambiar a otra versión en cualquier momento.
* **Ediciones sensibles:** existe la edición "Desktop" para ordenadores con interfaz gráfica de escritorio, "Server" para el uso de servidores, "Cloud" para la computación en la nube, así como "Core" para dispositivos IoT (Internet of Things).  Además, cualquier sistema puede actualizarse o reducirse en cualquier momento mediante la gestión de paquetes de instalación.
* **Gran soporte de plataformas:** no importa qué procesador se utilice, ya sea ARM 64, Raspberry Pi 2/3/4, PowerPC 64, s390 o Intel/AMD x86, Ubuntu lo soporta. Además, Ubuntu también está disponible en la Windows Store.
* **Kernel Live Patching:** esta técnica en el kernel de Linux puede cerrar las brechas de seguridad en el kernel sin reiniciar durante la operación. Esto pone al alcance de la mano la alta disponibilidad del ordenador.
* **Código abierto:** el código fuente es completamente abierto y se puede ver el sistema operativo hasta el último ángulo "bajo el capó". Además, puedes construir tu propio sistema operativo y también aportar tus propios cambios.
* **Rendimiento:** los últimos benchmarks han demostrado que incluso el altamente optimizado por Intel Clear Linux es apenas más rápido que Ubuntu 20.04.
* VPN rápida: con WireGuard, una red privada virtual (VPN) con una conexión encriptada se establece con especial rapidez (por ejemplo, a la red de la empresa). WireGuard tiene un diseño especialmente sencillo y sólo utiliza un conjunto limitado y seguro de algoritmos.
* **ZFS:** este sistema de archivos protege activamente todos los datos de los discos duros y SSD. Ofrece funciones como sumas de comprobación, copia en escritura, RAID, compresión, cifrado, deduplicación e instantáneas.  Especialmente esto último se hace cada 20 minutos, así como antes de las nuevas actualizaciones, en caso de errores se puede restablecer inmediatamente a un estado anterior, seguro.
* **Snaps:** con esta técnica las aplicaciones están completamente aisladas unas de otras y siempre contienen todas las librerías necesarias. Por muy mala que sea una aplicación, no afecta a las demás.
* **Directorio de usuario cifrado:** sólo cuando el usuario se conecta, su directorio de usuario es descifrado por la contraseña personal y, por tanto, utilizable. El directorio del usuario contiene todos los datos personales, configuraciones y archivos. Cuando se cierra la sesión, se vuelve a encriptar de forma segura y se protege así del espionaje o la manipulación.
* **Pruebas sin peligro** - simplemente descargue el archivo ISO de Ubuntu apropiado, transfiéralo a una memoria USB y luego arranque el ordenador desde la memoria USB. Ahora puedes probar Ubuntu ampliamente e instalarlo sólo si te gusta.
