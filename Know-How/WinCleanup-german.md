Windows 10: clean up the PC properly
====================

**The PC should also be cleaned up from time to time to avoid problems in advance. And before a major system update, cleaning up and making a backup should be mandatory. However, when cleaning up, the following order should be followed 

... ![Image](/img/MF.png) *By Markus Fleschutz* 🕑 *September 22, 2018*

## 1️⃣ Clean hardware.

First, clean the keyboard and mouse from crumbs and dust. Then unplug the PC, open the case and vacuum any dust (important before summer season to avoid overheating). 

2️⃣ Check hardware
--------------------------

All of today's hard drives and SSD's support the S.M.A.R.T standard ("Self-Monitoring, Analysis and Reporting Technology"). With a free software like *CrystalDiskInfo* (see [Download-Link](https://crystalmark.info/en/download/)) the condition of the device can be checked and evaluated. If errors come to light here, you should think about a backup and buying a replacement device now at the latest. 

3️⃣ Check file system
-----------------------------

Open the *Explorer* (e.g. with the key combination **WINDOWS** + **E**), then select **This PC** and then right-click on the drive to be examined and select **Properties** in the menu that opens. Now select the **Tools** tab and click **Check**.

4️⃣ Delete unnecessary software/apps.
------------------------------------

Right-click on the Windows tile at the bottom left corner and select **Apps and Features**. Now go through the program list, click on unnecessary programs and click on **Uninstall**.

5️⃣ Delete unnecessary files.
-----------------------------------

Again open *Explorer*, select **This PC** and then right click the **C:** drive and select **Properties** in the menu that opens and click **Cleanup**. Now the *Disk Cleanup** opens, which can be used to find and delete unnecessary files. 

6️⃣ Defragment file system
--------------------------------------

Defragmenting fills the gaps in the file system again to speed up accesses. To do this, open *Explorer* again, then select **This PC** and then right-click on the **C:** drive and select **Properties** in the menu that opens. Now select the **Tools** tab and click on **Optimize**.

All steps done? Congratulations 👍, your PC is now thoroughly cleaned up!
